# ComicConverter

**把漫画站导出的 EPUB，整理成 Kavita / Komga 能正确识别的 CBZ 库。**

按 OPF 的 `spine` 取真实页序、重算卷号、写全 ComicInfo，图片字节原样搬运 —— 不重编码、不降低画质。

![运行时](https://img.shields.io/badge/runtime-.NET%20Framework%204.8-512BD4)

**下载** → [Releases](https://github.com/RexLee0929/ComicConverter/releases)

| 安装包 | 大小 | 适用 |
|---|---|---|
| `ComicConverter-<版本>-setup.exe` | 约 550 KB | 想要开始菜单 / 桌面快捷方式、能从「已安装的应用」里卸载 |

不需要装 Python、不需要 .NET SDK，只要系统自带 .NET Framework 4.8。

## 30 秒上手

1. 安装后运行程序（开始菜单或桌面快捷方式）
2. 左栏 **源目录** 点「+ 添加目录」，选中放 EPUB 的文件夹（可加多个，会递归查找）
3. 左栏 **输出目录** 选 CBZ 要生成到哪
4. 中栏选 **目标服务器**（不确定就留「双兼容」）和 **阅读方向**（留「自动判断」）
5. 点 **预演** 看一眼命名对不对 → 点 **开始**

## 它解决什么

这些站点导出的漫画 EPUB 有四个坑，直接丢给漫画服务器就是踩雷：

| 问题 | 直接用会怎样 | 本程序 |
|---|---|---|
| 图片文件名是随机 ID（`vol-005318.jpg`），与页码无关 | 按文件名排序得到乱序漫画，翻两页不一定发现 | 读 OPF 的 `spine`，按真实页序重排 |
| 新旧两代生成器结构不同：早期 calibre 转的缺 `fixed-layout`，后期自研的每页套一层 HTML | KOReader 打开前者白屏；后者正文层干扰取图 | 直接抽 `spine` 指向的图片，无视包装层 |
| `calibre:series_index` 全是 `1.0` | 不管多少卷全排成第 1 卷，互相覆盖 | 从文件名与 OPF 重算卷号；无卷号的按自然序续编 |
| 没有 ComicInfo，或字段残缺 | 服务器刮削后排序、阅读方向全错 | 写全 `Series` / `Volume` / `Number` / `Manga` 等字段 |

## 功能

| 能力 | 说明 |
|---|---|
| **EPUB → CBZ** | 按 `spine` 取页序；图片字节原样拷贝，**不重编码、不降低画质** |
| **格式互转** | 已有 CBZ 在 Kavita / Komga 两种命名与元数据规则间互换，图片不动 |
| **双服务器格式** | Kavita 按 `Volume`（`系列 v01.cbz`）/ Komga 按 `Number`（`系列 #001.cbz`）/ 双兼容 |
| **阅读方向自动判断** | 先看页面比例认条漫，再按语言、出版社、标题文字、本地缓存、联网查证排出始发国；结论写进 ComicInfo 并缓存，同样内容不再联网 |
| **繁转简** | 内置 OpenCC 词表（台湾正体 / 通用繁体 → 简体），含假名的日文标题整条保留 |
| **番外处理** | 独立成系列，或作小数号接在正传后，两种策略可选 |
| **名称清洗** | 半角非法字符与全角 `：？＊／＼＜＞｜＂` 统一替换，跨平台不再踩雷 |
| **命名模板** | 文件名可自定义，变量 `{series}` `{vol}` `{vol3}`；原卷标签自动放进末尾括号 |
| **预演** | 只读元数据、不写文件，先看命名与页数再决定要不要跑 |
| **并行与续跑** | 默认 6 并发（可 1–32）；目标已存在即跳过，中断后重跑即可 |
| **配置持久化** | 所有设置存 `config.json`，下次打开自动恢复 |

## 选项说明

| 选项 | 默认值 | 说明 |
|---|---|---|
| 任务类型 | EPUB → CBZ | 「格式互转」处理已有 CBZ；该模式下没有「预演」按钮 |
| 源目录 | 空 | 可加多个，递归查找。转换模式找 `.epub`，互转模式找 `.cbz` |
| 输出目录 | 空 | 按系列自动建子目录，不会把上百个文件堆在一层 |
| 目标服务器 | 双兼容 | `Volume` 与 `Number` 都写，两边都能正确排序；切换时自动改文件名模板 |
| 文件名模板 | `{series} v{vol:02d}` | Komga 用 `{series} #{vol3}`；变量见[命名规则](#命名规则) |
| 阅读方向 | 自动判断 | 也可固定右开 / 左开 / 上到下；固定时不联网 |
| 繁转简 | 台湾正体 | 可选「不转」「台湾正体（`tw2s`）」「通用繁体（`t2s`）」 |
| 卷名 / 话名也繁转简 | 开 | 括号里的原卷标签跟着一起转；关掉则保留原始字形（`馮寶寶03`、`話532-554`） |
| 番外 / 特别篇 | 独立成系列 | 「接在正传后」会把番外 03 写成 `Number = 2.5` 这种小数号 |
| 压缩方式 | 不压缩 | 漫画图片本身已是压缩格式，`Deflate` 只省一点体积却明显更慢 |
| 并发数 | 6 | 1–32；机械硬盘上 4 左右更稳，SSD 上 8–12 更快 |
| 保留原卷标签 | 开 | 保留原始卷名，写成 `一人之下 v37 (话532-554).cbz` |
| 剔除站点水印页 | 开 | 按文件名剔掉 `createby.*`、`logo.png` 这类站点插入页 |
| 覆盖已存在文件 | 关 | 关闭时目标存在即计为「跳过」；开启后重做并覆盖 |
| 只处理前 N 个 | 关 | 大批量试跑用，确认效果再放开 |

**停止**：点停止后不再开始新文件，正在转换的那几个收尾后退出，已生成的 CBZ 都是完整的。

## 安装

运行安装包 `ComicConverter-<版本>-setup.exe`（Releases 页里最新下载的那个）：

1. **欢迎** → **选择安装模式**
   - **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicConverter`，不需要管理员权限
   - **为所有用户安装**：`%ProgramFiles%\ComicConverter`，会请求一次 UAC 提权
2. **许可协议**（MIT）→ **选择安装位置**（可浏览换目录，选完自动补上 `\ComicConverter` 一层）
   - 这个位置装过的话，页面上会写明已装的是哪一版、这次是更新 / 重装 / 降级，以及检测到的 `config.json` 路径
   - 路径写错或目标盘空间不足，直接在页内提示并把「下一步」置灰，不弹框
3. **附加任务**：桌面快捷方式 / 开始菜单快捷方式 / 安装完成后立即运行
4. **准备安装** → 安装 → **完成**（完成页可勾选「查看使用说明」）

装完在「设置 → 应用 → 已安装的应用」里正常卸载。点「卸载」时才检查程序是否在运行，命中就切到「正在运行」页：可点「结束进程并继续卸载」，也可「上一步」返回确认页。

卸载会移除程序文件、快捷方式、注册表登记与 WebView2 缓存；**`config.json` 默认保留**（可取消勾选一并删除），重装后设置还在。若有文件因为被占用没删掉，会进「卸载未完全成功」页并给出安装目录路径，可「重试」或关闭后手动删除。

### 文件都在哪

| 文件 | 位置 | 用途 |
|---|---|---|
| `config.json` | exe 同目录 | 全部界面设置；删掉等于恢复默认（也可用「输出 → 恢复默认设置」） |
| `error.log` | exe 同目录 | 未处理异常的堆栈；正常运行时不会生成 |
| `origin-cache.json` | `%LOCALAPPDATA%\ComicConverter\` | 阅读方向判定缓存，跟着用户走而不是跟着安装目录走 |

### 系统要求

- Windows 10 / 11（x64）
- .NET Framework 4.8（Win10 1803 以后系统自带）
- WebView2 Runtime（Win11 自带；Win10 未装时程序内会提示，也可从「工具 → 获取 WebView2 运行时」打开下载页）

## 命名规则

默认模板 `{series} v{vol:02d}`（Kavita / 双兼容）、`{series} #{vol3}`（Komga）。

| 原始文件名 | Kavita / 双兼容 | Komga |
|---|---|---|
| `Y之樂園 - 卷01 - 高橋直樹.epub` | `Y之乐园 v01.cbz` | `Y之乐园 #001.cbz` |
| `一人之下 - 03馮寶寶03 - 米二.epub` | `一人之下 v03 (冯宝宝03).cbz` | `一人之下 #003 (冯宝宝03).cbz` |
| `一人之下 - 話532-554 - 米二.epub` | `一人之下 v37 (话532-554).cbz` | `一人之下 #037 (话532-554).cbz` |
| `[Kox][○成]卷01.kepub.epub` | `○成 v01.cbz` | `○成 #001.cbz` |
| `WhatDoesTheFoxSay - 番外03.epub` | `WhatDoesTheFoxSay 番外/… 番外 v03.cbz` | `WhatDoesTheFoxSay 番外/… 番外 #003.cbz` |

几条约定：

- **原卷标签进括号**：Kavita 与 Komga 的解析器都把 `()` 当作附加信息，不会误读成卷号。例表里是开了繁转简的结果，关掉「卷名 / 话名也繁转简」就保留 `(馮寶寶03)`。
- **模板变量**：`{series}` 系列名、`{vol}` 卷号、`{vol:02d}` 两位补零、`{vol3}` 三位补零。
- **无卷号的卷**（`正傳Part1`、`連載前短篇`）按文件名自然序续编，不会全挤成 `v01` 互相覆盖。
- **卷号识别**：`第 N 卷 / 話 / 集`、`卷N`、`vN` / `vol.N`、`#N`、开头纯数字，依次尝试。
- **清洗**：`\ / : * ? " < > |` 换成 `_`；全角 `：？＊／＼＜＞｜＂` 同样处理；全角空格转半角；系列名截到 120 字、文件名 110 字、卷标签 40 字。
- **番外独立成系列**时目录名为 `{系列} 番外`，与正传分开，避免卷序互相污染。

## ComicInfo 字段

| 字段 | 来源 | 用途 |
|---|---|---|
| `Series` | 文件名解析（或 OPF 标题） | 两边归并系列 |
| `Volume` | 计算得出 | **Kavita** 排序 |
| `Number` | 计算得出（番外可用小数） | **Komga** 排序 |
| `Title` | OPF `dc:title` | 显示 |
| `PageCount` / `LanguageISO` | 实际内容 / OPF 语言 | 阅读器行为 |
| `Manga` | 阅读方向 | 右开写 `YesAndRightToLeft`，其余写 `No` |
| `Writer` / `Publisher` / `Summary` / `Genre` / `Year` | OPF 元数据 | 有就写，没有跳过 |
| `Format` | 番外标记 | `Special` |
| `Notes` | MOXBID / 版权 | 溯源 |
| `OriginCountry` | 自动判断 | 始发国（JP / KR / CN / TW / HK） |
| `ReadingMode` | 判定结果 | `rtl` / `ltr` / `ttb` |

`Volume` 和 `Number` **必须都写**：只写一个，另一边就会乱序。

> `OriginCountry` 与 `ReadingMode` 不是 ComicInfo 标准字段。Kavita（`XmlSerializer`）与 Komga（Jackson `@JsonIgnoreProperties(ignoreUnknown = true)`）都会忽略未知元素，不影响刮削；写进去是为了换目录重跑时能直接复用判定结果，不必再联网。

## 阅读方向怎么判断

选「自动判断」时的顺序，前面定了就不往下走：

1. **页面比例**（离线）：抽样 9 页量「高/宽」中位数。单页漫画约 1.4–1.6，条漫常在 3 以上，**≥ 2.0 直接判为上到下**。
2. **OPF 元数据**：`dc:language`（`ja` / `ko` / `zh-TW` …），或自定义 `comicconverter:origin`。
3. **出版社**：集英社 / 講談社 / 小學館 → 日本；東立 / 尖端 → 台湾；玉皇朝 / 天下 → 香港；bilibili / 快看 → 中国。
4. **标题文字**：含假名 → 日本，含谚文 → 韩国。
5. **本地缓存**：`origin-cache.json` 里的历史结论。
6. **联网查证**（最后手段）：用系列名、作者名查 Wikidata，取「国家/地区（P495）」或「作品语言（P407）」；动漫、电影、电视剧、游戏类目会被排除。

判完写进 `ComicInfo.xml`（`OriginCountry` + `ReadingMode`）并落本地缓存，**同一本第二次不再联网**。

联网时：单次超时 6 秒，一次扫描最多查 150 本、总耗时上限 120 秒，连续 3 次失败即判定「无网络」并全面退回离线判定 —— 断网只会让首轮慢十几秒，不会卡住转换。

手动选右开 / 左开 / 上到时**完全不联网**，只做离线判定来补 `OriginCountry`。

## 常见问题

**转完在 Kavita 里还是乱序？**
先确认输出时选的目标服务器和 Kavita 实际用的排序依据一致：Kavita 只认 `Volume`。如果当时选了 Komga，文件名是 `#001`，`Volume` 未必合预期。改回「双兼容」重跑一遍即可，图片不会被重编码。

**会改动我原来的 EPUB 吗？**
不会。源目录只读，全程只往输出目录写 `*.cbz`。

**转换中途关了程序 / 断电了？**
直接重跑即可：已经转换完的记「跳过」，不会重复打包。注意断电那一刻正在写的那个文件可能是残缺的，而它已经存在、会被当作已完成 —— 保险做法是勾上「覆盖已存在文件」再跑一遍，或先删掉输出目录里可疑的那个 `.cbz`。

**提示 WebView2 缺失、界面白屏？**
Win11 自带；Win10 多数已随 Edge 安装。缺的时候程序会显示提示和下载入口，也可用「工具 → 获取 WebView2 运行时」。

**繁转简把标题转坏了？**
含假名的日文标题会整条保留，不参与转换。若简体系列名被误转，把「繁转简」设为「不转」再跑（已生成的要开「覆盖」重做）。只想保留括号里的原始话名，关掉「卷名 / 话名也繁转简」即可，系列名照旧转换。

**杀毒软件报可疑？**
exe 没有代码签名，这是误报最常见的原因。可以先本地比对文件哈希，或者直接从源码自行编译（见 `DEVELOPMENT.md`）。

**能命令行批量跑吗？**
目前只有图形界面，没有命令行参数。要脚本化，可以预先写好 `config.json` 再启动程序。

## 已知限制

- 只处理**元数据与文件名**，图片里已经画上去的字无法转简体
- 自动判断可能判错（同名作品、简繁混写、冷门作品查不到），判错就在界面上手动指定方向；已写入 `OriginCountry` 的文件重跑不会被改
- 中文漫画基本刮不到元数据（ComicVine / AniList 对台版漫画命中率极低），写入的字段就是最终形态
- WebView2 Runtime 缺失时界面无法加载，只能看到下载提示
- 只支持 Windows，没有 Linux / macOS 版本计划
