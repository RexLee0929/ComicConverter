# ComicConverter 1.0.4

界面与交互大改版：菜单按程序功能重排，能就地提示的不再弹窗，安装 / 卸载向导同步打磨；转换逻辑与 1.0.3 一致。

## Highlights

- **菜单重排**：一级菜单改成 `转换 / 输出 / 工具 / 帮助`，跟着程序做什么长出来，不再是「文件 / 编辑 / 查看 / 工具」那套模板；预演命名、开始转换、停止转换也进了「转换」菜单
- **弹窗只剩一个**：成功、已复制、已保存走状态栏或页面提示条，清缓存 / 恢复默认改成页面底部的内联确认条（主按钮语义红、默认焦点在「取消」）；只有没料到的错误才弹自绘错误框
- **出错不再无声**：未捕获异常写 `error.log` + 状态栏红字 + 错误框（带「打开日志」），界面照常可用
- **重复启动把已有窗口叫到前面**：不再弹「程序已经在运行」
- **安装器收尾**：系统消息框全换成自绘小窗（不响提示音），提权后从许可协议页接着走，失败页主按钮归位

完整变更列表见 [CHANGELOG.md](https://github.com/RexLee0929/ComicConverter/blob/main/CHANGELOG.md)。

## 下载

下载 `ComicConverter-1.0.4-setup.exe` 运行即可：

- **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicConverter`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\ComicConverter`

从 1.0.1 / 1.0.2 / 1.0.3 直接安装即覆盖升级，设置保留（想恢复默认设置，在安装向导里勾「覆盖现有配置」）。

## 系统要求

Windows 10 / 11（x64）；.NET Framework 4.8（系统自带）；WebView2 Runtime（Win11 自带，Win10 未装时程序会提示下载）。

## 已知限制

- 图片里已经画上去的字无法转简体
- 自动判断可能判错，判错就在界面手动指定方向
- 中文漫画基本刮不到元数据（ComicVine / AniList 对台版命中率极低）
- WebView2 Runtime 缺失时界面无法加载，只显示下载提示
- 只支持 Windows，没有 Linux / macOS 版本计划
