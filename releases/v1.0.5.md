# ComicConverter 1.0.5

安装 / 卸载向导的收尾版：卸载会先核实真的删干净了，安装位置页会说清本机已装的是哪一版；转换逻辑与 1.0.4 一致。

## Highlights

- **卸载不再虚报成功**：删完先复查安装目录，还有文件没删掉就进「卸载未完全成功」页，可「重试」或「关闭」后手动清理
- **卸载前先看清再动手**：向导先给卸载内容、安装位置、要清理的项和「保留配置文件」选项，点「卸载」那一刻才检查程序是否在运行，命中再切「正在运行」页
- **安装位置页说清本机情况**：该位置已装 `vX` 时会写明「将更新 / 与安装包相同将重装 / 比安装包新将降级」，有配置就显示配置路径，装在别处也会提示那一份的位置
- **保留配置写得明白**：卸载完成页的「配置文件已保留」分四行 —— 目录、留下了哪些文件、文件完整路径、（重装后自动沿用）

完整变更列表见 [CHANGELOG.md](https://github.com/RexLee0929/ComicConverter/blob/main/CHANGELOG.md)。

## 下载

下载 `ComicConverter-1.0.5-setup.exe` 运行即可：

- **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicConverter`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\ComicConverter`

从 1.0.1 / 1.0.2 / 1.0.3 / 1.0.4 直接安装即覆盖升级，设置保留（想恢复默认设置，在安装向导里勾「覆盖现有配置」）。

## 系统要求

Windows 10 / 11（x64）；.NET Framework 4.8（系统自带）；WebView2 Runtime（Win11 自带，Win10 未装时程序会提示下载）。

## 已知限制

- 图片里已经画上去的字无法转简体
- 自动判断可能判错，判错就在界面手动指定方向
- 中文漫画基本刮不到元数据（ComicVine / AniList 对台版命中率极低）
- WebView2 Runtime 缺失时界面无法加载，只显示下载提示
- 只支持 Windows，没有 Linux / macOS 版本计划
