# ComicConverter 1.0.1

首个公开版本。把漫画站导出的 EPUB 整理成 Kavita / Komga 能正确识别的 CBZ 库。

## Highlights

- **EPUB → CBZ**：按 OPF 的 `spine` 取真实页序，图片字节原样拷贝，不重编码、不降低画质
- **双服务器格式**：Kavita（`Volume` 排序）/ Komga（`Number` 排序）/ 双兼容，两个字段都写
- **阅读方向自动判断**：页面比例先认条漫，再按元数据 → 出版社 → 标题文字 → 本地缓存 → Wikidata 查始发国；结论写进 ComicInfo 并缓存，同一本不再联网
- **繁转简**：内置 OpenCC 词表（台湾正体 / 通用繁体），含假名的日文标题整条保留
- **格式互转 / 番外处理 / 命名模板 / 预演 / 断点续跑**：详见 [README](https://github.com/RexLee0929/ComicConverter#readme)

## 下载

下载 `ComicConverter-Setup.exe` 运行即可：

- **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicConverter`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\ComicConverter`

完整变更列表见 [CHANGELOG.md](https://github.com/RexLee0929/ComicConverter/blob/main/CHANGELOG.md)。

## 系统要求

Windows 10 / 11（x64）；.NET Framework 4.8（系统自带）；WebView2 Runtime（Win11 自带，Win10 未装时程序会提示下载）。

## 已知限制

- 图片里已经画上去的字无法转简体
- 自动判断可能判错，判错就在界面手动指定方向
- 中文漫画基本刮不到元数据（ComicVine / AniList 对台版命中率极低）
- WebView2 Runtime 缺失时界面无法加载，只显示下载提示
- 只支持 Windows，没有 Linux / macOS 版本计划
