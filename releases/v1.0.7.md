# ComicConverter 1.0.7

这一版调整了窗口与界面提示，并让意外出现的页面确认框默认取消。

## Highlights

- **弹窗宽度适应内容**：关于窗口和错误框不再使用固定宽度
- **确认兜底更谨慎**：页面意外发出原生确认框或输入框时取消操作并提示
- **日志更易读**：转换与格式互转结果直接标为「成功」或「失败」
- **界面细节调整**：菜单图标、选中标记和状态栏配色更新

## 下载

下载 `ComicConverter-1.0.7-setup.exe` 运行即可：

- **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicConverter`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\ComicConverter`

完整变更见 [CHANGELOG.md](https://github.com/RexLee0929/ComicConverter/blob/main/CHANGELOG.md)。

## 系统要求

Windows 10 / 11（x64）；.NET Framework 4.8（系统自带）；WebView2 Runtime（Win11 自带，Win10 未装时程序会提示下载）。

## 已知限制

- 只处理**元数据与文件名**，图片里已经画上去的字无法转简体
- 自动判断可能判错（同名作品、简繁混写、冷门作品查不到），判错就在界面上手动指定方向；已写入 `OriginCountry` 的文件重跑不会被改
- 中文漫画基本刮不到元数据（ComicVine / AniList 对台版漫画命中率极低），写入的字段就是最终形态
- WebView2 Runtime 缺失时界面无法加载，只能看到下载提示
- 只支持 Windows，没有 Linux / macOS 版本计划
